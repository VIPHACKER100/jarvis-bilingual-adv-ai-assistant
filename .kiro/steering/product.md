# JARVIS Product Overview

## What is JARVIS?

JARVIS is a bilingual (English/Hindi) AI-powered system controller designed for Windows, macOS, and Linux. It provides voice-activated control over system operations, file management, application control, and various productivity tasks.

## Core Value Proposition

- **Voice-First Interface**: Hands-free system control with "Hey JARVIS" wake-word detection
- **Bilingual Support**: Natural language processing in both English and Hindi (Hinglish)
- **Comprehensive System Control**: 100+ commands covering system monitoring, window management, file operations, media control, and automation
- **Cross-Platform**: Works on Windows, macOS, and Linux with platform-specific optimizations

## Target Users

- Power users who want efficient voice-controlled system management
- Multilingual users (English/Hindi speakers)
- Developers and professionals seeking automation and productivity enhancement
- Users requiring accessibility features for hands-free computer operation

## Key Features

- **System Control**: CPU/GPU monitoring, power management, volume control, notifications
- **Window Management**: Application launching, window positioning, desktop control
- **File Operations**: Advanced search, OCR text extraction, PDF manipulation, batch processing
- **Voice Recognition**: Local processing with Web Speech API integration
- **Mobile Companion**: Secure pairing with mobile devices for remote control
- **Autonomous Intelligence**: ReAct framework for complex query handling and proactive suggestions

## Architecture Philosophy

- **Privacy-First**: Local processing with no data collection
- **Security-Conscious**: Confirmation systems for dangerous operations, safe file handling
- **Modular Design**: Extensible router-based backend architecture
- **Real-Time**: WebSocket-based communication for responsive interactions
